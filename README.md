# Tarjeta de Presentación Digital - C&G Inmobiliarios 🏠✨

¡Bienvenido al repositorio de la tarjeta de presentación digital de **C&G Inmobiliarios**! Este proyecto consiste en una tarjeta web optimizada para dispositivos móviles, diseñada específicamente para ser accedida de forma rápida a través del escaneo de un código QR.

La interfaz replica fielmente el diseño impreso original, incorporando una estructura geométrica en forma de tejado y botones de contacto interactivos.

---

## 🚀 Características

* **Diseño Fiel al Original:** Silueta superior adaptada en punta tipo "techo de casa" mediante geometría CSS avanzada (`clip-path`).
* **Interactividad Móvil (2x2):** Cuadrícula de contacto optimizada para pantallas táctiles que permite acciones directas:
  * **WhatsApp:** Abre chat directo con el número preconfigurado.
  * **Facebook:** Redirecciona al perfil oficial de la inmobiliaria.
  * **Correo Electrónico:** Lanza la app de mail predeterminada (`mailto:`) con el correo de destino listo.
  * **Ubicación:** Enlaza directamente con la dirección en Google Maps.
* **Fondo Dinámico:** Textura decorativa con micro-punteado y órbitas circulares sutiles en CSS que le dan profundidad al fondo azul sin distraer la lectura.
* **Tipografía Profesional:** Integración de fuentes modernas (*Oswald* y *Roboto*) mediante Google Fonts.

---

## 🛠️ Tecnologías Utilizadas

* **HTML5:** Estructura semántica del contenido.
* **CSS3:** Estilos independientes, Flexbox, CSS Grid y recortes poligonales avanzados.
* **FontAwesome v6.4.0:** Iconografía vectorial de alta resolución para redes y servicios.
* **Google Fonts:** Fuentes tipográficas web seleccionadas para el proyecto.
